# 依洛嘉面膜保養官方旗艦店

平價保養品第一品牌。純 HTML / CSS / JavaScript 靜態網站，粉色系雜誌風，支援 RWD。

## 目錄結構

```
index.html        首頁
css/style.css     樣式（含 RWD 斷點）
js/main.js        選單、輪播、商品渲染、購物車
elg-*.md          網站資料來源（選單、最新商品、輪播圖）
```

## 使用方式

直接用瀏覽器開啟 `index.html` 即可，不需要建置工具。

## 功能

- 三層 Mega Menu，手機版為漢堡選單加手風琴
- 首頁輪播圖（自動播放、箭頭、圓點、觸控滑動）
- 最新商品 10 項，可加入購物車（以 localStorage 儲存）
- 幣別顯示切換（TWD / USD，匯率為示意值）
- RWD 斷點：手機（小於 768px）、平板（小於 1024px）、桌機

## 注意事項

- 圖片直接引用外部 CDN，正式上線前建議下載到本地。
- 「前往結帳」尚未串接金流，僅為示範。
- `elg-homepagefb.md` 內容與輪播圖檔重複，社群連結的 Facebook 與 YouTube 網址為推測值，需確認。
